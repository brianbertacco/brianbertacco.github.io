# Brian Bertacco | Aerospace Engineering Portfolio

Static website for **brianbertacco.github.io**. Open `index.html` locally or
publish the site root using GitHub Pages from `main` / `/ (root)`.

## Content

Twelve engineering case studies, an English biography, CV and ten original
project reports. Original figures have source captions. Team authorship and
individual responsibilities are distinguished in every case study.

## Files

- `index.html`: homepage, project filters and search, biography and contact.
- `projects/`: standalone case-study pages.
- `assets/images/`: figures extracted from the supplied reports.
- `documents/`: original report PDFs and CV.
- `style.css`, `script.js`: shared styling and interaction.
- `project-content.json`: editable content reference, not a runtime data source.
- `IMMAGINI.md`: image-to-project mapping and replacement instructions.
- `LEGGIMI.txt`: Italian setup and maintenance instructions.
- `SOURCES.md`: source mapping and content decisions.

There are no framework, font, analytics or CDN dependencies. JavaScript adds
filtering, search, a mobile menu and image enlargement. Project content is
available as static HTML. No licence is granted by this package; report and
figure authorship remains with the respective authors.
